# E-Commerce Sales Analysis

## Project Overview

This project analyzes 5,000 e-commerce orders to understand sales performance, customer behavior, product performance, regional trends, and business performance.

The project demonstrates an end-to-end data analysis workflow using Python, SQL, and Tableau.

## Tools & Technologies

- Python
- Pandas
- NumPy
- SQL
- SQLite
- Tableau
- Jupyter Notebook

## Dataset

The dataset contains 5,000 e-commerce orders with information about:

- Order date
- Customer
- Product category
- Region
- Quantity
- Unit price
- Discount
- Payment method
- Delivery days
- Customer rating
- Revenue

## Analysis Performed

### Python & Pandas

- Data cleaning and validation
- Missing-value checks
- Duplicate checks
- Data type conversion
- Revenue validation
- Sales performance analysis
- Product category analysis
- Regional analysis
- Customer analysis
- Delivery and customer-rating analysis
- Discount and revenue analysis

### SQL

Business analysis was performed using SQLite, including:

- Overall sales KPIs
- Revenue by product category
- Revenue by region
- Top customers
- Monthly revenue trends

## Key Findings

- Total revenue: approximately ฿5.11 million
- Total orders: 5,000
- Unique customers: 989
- Average order revenue: approximately ฿1,022
- Electronics generated the highest total revenue.
- West generated the highest regional revenue.
- The dataset contains 20,224 units sold.
- Average delivery time was approximately 6.1 days.
- Average customer rating was approximately 3.0.
